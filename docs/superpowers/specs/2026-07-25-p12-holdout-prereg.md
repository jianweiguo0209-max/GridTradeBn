## 5. 预注册判据（跑前写死，不许挪门柱）

### 主判据（PASS 的充要条件）

> **臂 B（p12×St5）在 HOLD-C 与 HOLD-D 两窗中的每一窗，均满足：**
> **① Calmar_B ≥ Calmar_A　且　② MDD_B ≤ MDD_A × 1.3**

**最差窗规则**：两窗**均**须满足；任一窗任一条不满足 → **FAIL**。不做两窗平均、
不做 Σ 求和、不允许"一窗大胜补另一窗小负"。

### 副判据（归因，不改变主裁决）

臂 C（p12×s030）在两窗同报同样两项。用于把"选币器贡献"与"执行链贡献"分开：

- B 过 C 也过 → 收益主要来自**选币器**（p12），链是放大器；
- B 过 C 不过 → 收益依赖 **St5 链**与 p12 的交互（更脆，实盘化需连链一起搬）；
- B 不过 C 过 → St5 链在新 regime 是**负担**，候选应退回 p12×s030 另立项；
- 均不过 → 整条线判死。

### 背景（不设门）

臂 D（p12×St4）、各臂 ret / worst_grid / 退出原因分布 / 破网爆仓数照报，只作形态观察。

### 执行细则（防止事后解释权）

1. **指标口径**：`SW.metrics()` 原样——Calmar = 年化/MDD（年化按窗天数折算），
   MDD 为正数（越小越好），组合净值 = 12 offset lane 各自复利后等权平均。
2. **平局**：`Calmar_B ≥ Calmar_A` 取**含等号**；数值比较保留到小数点后 1 位
   （与 geo_final 报表同精度），四舍五入后相等即算满足。
3. **负 Calmar**：两臂均可能为负（HOLD-A 锚就是 −2.9）。判据仍是代数序关系
   （−2.0 ≥ −2.9 成立 = 少亏也算赢）。**不因符号为负而改判据。**
4. **Calmar = inf**：若某臂 MDD < 1e-9 导致 inf，该窗该臂记为**不可比**，
   整体判 **FAIL**（拒绝靠退化数值取胜）。
5. **数据缺口**：若某窗某臂因归档缺口导致有效轮数 < 该窗锚臂轮数的 95%，该窗判**不可比**→
   整体 FAIL（拒绝"少跑几轮刚好躲过雷"）。
6. **锚不复现即停手**：留出窗的锚臂无历史存档可对（新窗），故改验**结构自检**——
   锚臂 12 offset 齐全、破网/爆仓数为 0 量级、轮数与预期一致；判定窗的锚必须先逐位
   复现 BASE_TD（见 §6），否则整场停手查保真度。
7. **一次性**：两留出窗各臂**只跑一次**。不复跑、不换种子、不调窗边界。若因程序错误
   须重跑，须在本文件"执行记录"追加说明错误性质与重跑范围。
