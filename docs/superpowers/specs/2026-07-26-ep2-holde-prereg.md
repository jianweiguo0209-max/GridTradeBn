## 4. 部署门（唯一裁决，组合口径）

> **HOLD-E（2025-06-01 ~ 2025-08-14）上，主臂 `EP2_s030` 须同时满足三条：**
> **① Calmar ≥ 锚臂　② MDD ≤ 锚臂 × 1.3　③ ret > 锚臂**

三条**全过**才 PASS；任一条不满足即 **FAIL**。其余 17 臂同跑同报，**只作参考，不参与
裁决**，且**不得因某参考臂过门而改立候选**。

### 执行细则（封死事后解释权）

1. **指标口径**：`SW.metrics()` 原样。
2. **平局**：条①含等号，比较保留 1 位小数；条③**不含等号**（须严格大于）。
3. **负 Calmar**：按代数序，不因符号为负改判据。
4. **inf / 缺口**：主臂 Calmar 为 inf，或有效格数 < 锚的 95% → 判**不可比 = FAIL**。
5. **一次性**：HOLD-E 只跑一次，不复跑、不换种子、不调窗边界。
6. **锚结构自检**：HOLD-E 无存档可对，改验 12 offset 齐全、破网/爆仓 0 量级、轮数合理。
7. **F99 系按 carry 标签解读**（brief 修订三）：若 F99 臂超额集中于深负费率窗且复苏窗
   回吐，按资金费 carry 读数，不按选币边读数。主臂非 F99，故此条不影响裁决。

## 5. 已知弱点与不利先验（**写在跑 HOLD-E 之前**）

判定八窗**全部污染**（选币器与链皆探索于其上），只做估计不做裁决。以下须记录在案：

1. **主臂判定段三条门只 6/8 窗全过**，失败于 **HOLD-B**（C 1.7<4.5、MDD 5.14>3.12、
   ret 1.38<1.75）与 **HOLD-D**（C −4.3<−3.0、MDD 9.36>5.97、ret −8.39<−2.46）。
2. **两个失败窗同属"牛市顶部/剧震"型**（2024-10~11、2024-12~2025-01），且**与上一战
   p12 团灭的窗完全相同**（p12 在 HOLD-D 的 MDD 也是 11.5~15.6）。
   ⇒ 这是**结构性弱点**而非噪声：高波动选币器在单边剧震中回撤失控。
   **若 HOLD-E(2025-06~08) 恰为此类 regime，主臂大概率 FAIL。**
3. **多臂折扣极重**：本周探针累计 ~57 臂 + 本战役 18 臂；且三选币器共享 `Er_2 + p12`
   内核（smoke test 中同轮选出同一币），**有效独立读数远少于 18**。18/18 全过锚这一
   事实虽强，但不能按 18 个独立证据计。
4. **面板 join 残余风险**（沿用上一战 §5）：`Reg_v2_5` 完全一致、`Sgcz_5` 差 ≤3.3e-16
   （1 ulp），HOLD-A 抽样 60/60 轮 top-1 一致；`rank(method='first')` 对并列敏感。
   **若裁决贴线（任一条差距在 0.2 Calmar / 0.3pp MDD / 0.3pp ret 以内），须重跑 POOL
   同源复核后再定。**

## 6. 机制假设（可证伪，写明以便被推翻）

`Er_2`（围绕 EMA 的均衡振荡度）作为**燃料否决器**：`p12` 排燃料多寡，`Er_2` 否决
"波动大但实为单边趋势"的币 ⇒ **"振荡门控燃料"**。可证伪推论：

- 若假设为真，主臂应在**趋势/碎震皆可**的窗稳定优于锚，且 **MDD 不随收益放大**
  （判定段已见：W1/W2/OOS 的 MDD 均**低于**锚）；
- 若假设为假（Er_2 只是又一个波动代理），则 MDD 应与收益同向放大，
  **HOLD-E 上会重演 p12 式的回撤失控**。
- 第三因子（Sgcz_5 / Reg_v2_5）**有害而非冗余**：判定段排序 EP2 > D_REP > D_ESP，
  加因子系统性变差。这是本战役对 brief 原假设的修正。
