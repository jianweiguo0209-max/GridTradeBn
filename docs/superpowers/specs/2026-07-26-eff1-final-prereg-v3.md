## v4 修订（2026-07-26，用户令"只扫描参数，然后最优参数终审"）——协议改为三段式

**流程**：①九窗全样本扫描（scan-brief 五层）→ ②按下述先声明规则合成 eff1-opt 并冻结
→ ③HOLD-F/JUL26 终审。裁决窗数据可并行下载建库，但**任何臂不得在其上运行直至 opt 冻结**。

**参数选择规则（写死于扫描出数之前，防赢家诅咒）**：
1. **逐轴平台中点原则**：每轴取"九窗合计 Calmar 的平台"（相邻点差 < 该轴噪声带）的
   **中点**，不取峰值点；轴平（极差在噪声内）→ **保持现值**（最小改动原则）。
2. 跨轴合成 = 各轴独立选点的坐标合成；合成后九窗全轮跑一次确认无交互劣化
   （劣于最佳单轴改动 → 退回单轴改动版）。
3. 公式脆弱性层（P4）**不参与选点**——只出"平台/尖峰"置信度报告，eff 公式保持原样。
4. top-K 层若非平台（K>1 显著优）可入合成，组合语义按生产 choose_symbols。

**终审臂（修订）**：锚 + **eff1-opt（主裁决对象,§3 修正门三条不变）** + eff1×s030 原样
（参考臂,只报不裁,不得借其复活——单候选纪律）。

**风险披露**：相比零修改版,opt 携带九窗调参的选择效应,新窗预期收缩加大——此为用户
知情选择的经典协议(s030 同款出身),门形不变以对冲。
