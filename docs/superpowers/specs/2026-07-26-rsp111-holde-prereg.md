## 3. 部署门（唯一裁决，组合口径）

> **HOLD-E（2025-06-01 ~ 2025-08-14）上，主臂 `rsp_St5` 须同时满足三条：**
> **① Calmar ≥ 锚臂　② MDD ≤ 锚臂 × 1.3　③ ret > 锚臂**

三条**全过**才算 PASS；任一条不满足即 **FAIL**。其余四个 RSP 臂在 HOLD-E 同跑同报，
**只作参考，不参与裁决**，且**不得因某参考臂过门而改立候选**。

### 执行细则（封死事后解释权）

1. **指标口径**：`SW.metrics()` 原样（Calmar=年化/MDD，MDD 为正数，组合净值=12 offset
   lane 各自复利后等权平均）。
2. **平局**：条①含等号，数值比较保留到小数点后 1 位；条③**不含等号**（须严格大于）。
3. **负 Calmar**：仍按代数序（−2.0 ≥ −2.9 成立）。不因符号为负改判据。
4. **inf / 数据缺口**：主臂 Calmar 为 inf，或主臂有效格数 < 锚臂的 95% → 判**不可比 = FAIL**。
5. **一次性**：HOLD-E 只跑一次，不复跑、不换种子、不调窗边界。因程序错误须重跑者，
   须在"执行记录"追加说明。
6. **锚结构自检**：HOLD-E 无历史存档可对，改验 12 offset 齐全、破网/爆仓为 0 量级、
   轮数与预期一致。

## 4. 判定段已知不利先验（**写在跑 HOLD-E 之前**，免得事后自我说服）

判定八窗**全部污染**（选币器与链参数皆探索于其上），只做估计不做裁决。但以下事实
必须在裁决前记录在案：

1. **RSP 全部五臂的合计 Calmar（0.90~1.49）均低于锚（3.22）**；中位数上锚 +0.80、
   RSP 五臂全为负。胜锚窗数仅 3~4/8。
   ⇒ RSP111 在自己的主场（全污染、随便挑）就整体输给现役锚。
2. **主臂 St5 的 1.49 几乎全靠 IS 单窗的 24.7 撑起**，其余七窗中位 −2.15。
   主臂选择事实上由 IS 单窗主导（其余窗各臂差异多在 ±3 内，IS 差异达 20+）。
3. **决定性的一条**：判定八窗中，**St5 的 MDD 8/8 全部超过锚×1.3**——
   连它唯一大胜的 IS 窗也超（6.15 vs 上限 5.16）。部署门条②在判定段**一次都没过过**。
   ⇒ RSP 是用显著更大的回撤换收益，而部署门恰恰卡回撤。
4. **探针已被组合级反证第四次**：探针六窗合并 +9.4bp/t2.18（v2固3），组合级整体翻负；
   W2（探针 +4.5/t0.37 → 实际输锚 20 个 Calmar）、HOLD-A（+12.7/t1.15 → 实际输锚）
   为**符号反转**，非单纯收缩。brief §4 的 stride-5 前科再次应验。

**综上，先验上本战役大概率 FAIL。** 但先验不是判据——HOLD-E 照跑，按 §3 机械裁决。

## 5. 残余风险（若结果贴线必须处理）

因子来源为**面板 join** 而非重跑 POOL 同源（用户令"第一轮效率第一"）。前置验证：
面板与回放的 `Reg_v2_5` **完全一致**、`Sgcz_5` 差 ≤3.3e-16（float64 1 ulp）；
HOLD-A 抽样 **60/60 轮 RSP111 top-1 一致**。残余风险：`rank(method='first')` 对并列敏感，
ulp 级差异理论上可翻转排名（抽样覆盖 0.5%，未见实例）。
**若 HOLD-E 裁决结果贴线（任一条判据差距在 0.2 Calmar / 0.3pp MDD / 0.3pp ret 以内），
须以重跑 POOL 同源复核后再定生死。**
